# Contributing

Thanks for your interest in contributing to `winehq-codespaces`.

## Development flow

1. Fork the repository and create a feature branch.
2. Keep changes focused and small.
3. Test your updates locally:
   - `bash -n .devcontainer/install-winehq.sh`
   - `bash -n scripts/run-winegui.sh`
4. Open a pull request that explains what changed and why.

## Reporting issues

Please include:

- Your Codespaces image details (`cat /etc/os-release`)
- The command you ran
- Relevant error output
